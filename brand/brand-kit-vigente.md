# Brand Kit vigente — Publicomp

**Estado:** Definitivo (2026-09-10). Reemplaza el territorio visual anterior — ver [`territorio-visual-publicomp.md`](territorio-visual-publicomp.md) (marcado como histórico/descartado).
**Fuente:** [`Brandkit/Publicomp_BrandKit.pdf`](Brandkit/Publicomp_BrandKit.pdf) — documento desarrollado por el cliente fuera de esta sesión. Este archivo es un resumen de referencia rápida; ante cualquier duda, el PDF manda.

**Nombre de marca:** Publicomp (con "P" mayúscula al escribir el nombre en texto corrido; el wordmark del logo usa minúscula "publicomp" por diseño).

---

## 01 — Esencia de marca

- **Concepto:** comunicar tecnología, precisión, potencia y confianza. Base oscura y técnica + rojo energético como firma visual.
- **Personalidad:** moderna · tecnológica · profesional · contundente · dinámica · confiable
- **Dirección visual:** fondos negro/grafito, superficies metálicas, geometría angular, iluminación roja controlada, alto contraste. Evitar que quede excesivamente "gamer" — debe sostenerse en contextos corporativos.
- **Tono:** seguro, directo, profesional; mensajes cortos orientados a soluciones.

## 02 — Sistema de logo

- Símbolo: "P" angular, acabado grafito/acero + rojo.
- Wordmark: "publicomp", blanco/plata.
- El rojo es **acento**, no relleno dominante.
- Reglas: mantener proporciones originales · no agregar efectos fuera del sistema · no usar sobre fondos de bajo contraste · versión plana (sin 3D) para impresión chica · dejar área de seguridad alrededor del logo.

## 03 — Paleta cromática

| Color | Hex | RGB | Uso |
|---|---|---|---|
| Negro técnico | `#07090C` | 7/9/12 | Fondos, piezas premium |
| Grafito | `#15181D` | 21/24/29 | Paneles, superficies |
| Carbón | `#24282E` | 36/40/46 | Secundarios |
| Rojo Publicomp | `#E50914` | 229/9/20 | Acentos, P, CTA |
| Rojo profundo | `#8B0008` | 139/0/8 | Degradados y profundidad |
| Plata | `#D9DEE4` | 217/222/228 | Wordmark y textos premium |
| Blanco | `#F5F7FA` | 245/247/250 | Texto sobre oscuro |

**Proporción sugerida:** 65% negros/grafitos · 20% plata/blanco · 15% rojo.

## 04 — Tipografía

**Montserrat** (o sans geométrica similar) para titulares y comunicación visual. Sans neutra de alta legibilidad para texto largo.

| Nivel | Tratamiento |
|---|---|
| H1 | Mayúsculas o minúsculas, Bold/ExtraBold, alto contraste |
| H2 | Bold, rojo Publicomp para acentos |
| Cuerpo | Regular, blanco/plata, interlineado amplio |
| Datos | Medium/Semibold, blanco, tamaño reducido |

## 05 — Estilo gráfico

Superficies de carbono, metal cepillado, grafito, diagonales y curvas amplias. Líneas rojas como guías visuales o iluminación — siempre con moderación.

## 06 — Aplicaciones

- **Tarjeta personal:** frente con logo grande sobre negro/grafito + acento rojo; dorso con datos de contacto jerarquizados + una línea/acento rojo.
- **Redes sociales:** avatar = símbolo P aislado. Portadas = textura oscura + línea roja + wordmark. Publicaciones = titulares blancos + CTA rojo.
- **Web:** base `#07090C`, bloques `#15181D`, texto `#F5F7FA`, secundarios `#D9DEE4`, CTA `#E50914`.
- **Impresión:** priorizar versión plana del logo en tamaños chicos; reservar efectos metálicos/3D para piezas grandes o premium.

## 07 — Guía rápida

| Elemento | Decisión |

## Nota de continuidad estratégica

Esta dirección visual (oscura, roja, estética tech/gaming con acabados metálicos) es un cambio notable respecto al brief estratégico original ([`brief-estrategico-publicomp.md`](brief-estrategico-publicomp.md)), que definía personalidad "sólido, claro, cercano, capaz" y priorizaba un tono cálido y accesible para PyMEs argentinas. No se modificó el brief estratégico en esta actualización — solo la identidad visual. Si el cambio de dirección visual también implica un cambio de posicionamiento/tono, conviene revisar el brief en algún momento para que quede consistente.
